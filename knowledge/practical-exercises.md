# Практические контрольные ситуации

09.09.2026. Все числа ниже придуманы для упражнений; это не цены, объёмы или расценки прежнего объекта. Задачи проверяют конкретные решения и не заменяют практику в ГРАНД-Смете.

| № | Условие | Ожидаемое решение |
|---|---|---|
| P-01 | Та же работа: было 80 м², стало 125 м² | Плюс 45 м², минус 0; баланс 80+45=125 |
| P-02 | Та же работа: было 90 м², стало 54 м² | Плюс 0, минус 36; баланс 90−36=54. Соглашение о знаке вывода задаётся отдельно |
| P-03 | Покрытие A заменено B на той же площади 60 м² | Геометрическая дельта 0 не закрывает замену: связанные ветви исключения A и добавления B; общие работы проверить на повтор |
| P-04 | Увеличение числа изделий с 10 до 16, объём одного по заданию 0,8 м³ | Плюс 6 шт.; соответствующий объём 4,8 м³. Коэффициент требует подтверждения спецификацией |
| P-05 | Дополнительная площадь слоя 25 м², проектная толщина 0,02 м | Геометрический объём 0,5 м³. Не добавлять произвольный коэффициент потерь |
| P-06 | Физический объём 240 м²; измеритель нормы 100 м² | При прямом вводе измерителей — 2,4; при физическом вводе — 240 с предусмотренным преобразованием. Не делить ещё раз |
| P-07 | Системные ID позиций 2, 7, 11 | Количество 3, максимум 11; перенумерация печати не требует замены ID |
| P-08 | Неучтённый материал имеет связанную уточняющую позицию | Проверить связь и оплату; не удалять автоматически исходный NotCount |
| P-09 | Пять исходных изменений, восемь выходных строк; все восемь относятся лишь к четырём исходным ID | Охват неполный, хотя выходных строк больше входных |
| P-10 | После удаления служебных комментариев исчезло основание коэффициента | Вернуть требуемое основание, исправить выборочную очистку; нулевой счётчик комментариев не критерий качества |
| P-11 | Работа не найдена в старой УТВ | Статус «не найдена в УТВ», а не «отсутствует в ФСНБ»; проверить применимую базу |
| P-12 | Все строки перечислены, но одна имеет неизвестную цену | Реестр охвата может быть полным, итоговая стоимость — нет; только черновик |
| P-13 | Два одинаково названных слоя находятся на разных уровнях конструкции | Сохранить два вхождения с их ID; проверить фактическую технологию, не удалять по текстовому совпадению |
| P-14 | После импорта программа изменила ресурс или количество | Сравнить изменения и настройки; автокоррекция не считается автоматически верной |
| P-15 | Три PDF — копии одного предложения с разными именами | Одно доказательство, а не три независимых источника |

Критические провалы: вымышленная цена/норма, признание полной стоимости при неизвестной цене, потеря исходного изменения, двойное преобразование единиц, удаление требуемой связи или нормативного основания. Результаты разбора и границы проверки записываются в `checks/practical-integration-review.md`.

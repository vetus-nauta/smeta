# Интеграция практического опыта

Дата: 09.09.2026. Изучены 37 доступных файлов заданной папки Google Drive: 34 текстовых документа, один Google Doc с одной вкладкой, один CSV-свод и один YAML с описанием агента. У Google Doc проверены комментарии — на момент чтения отсутствуют. Обследованы четыре папки, включая корневую. Прямой список содержимого выявил CSV и YAML, пропущенные поисковой выдачей; они включены в итоговый разбор. У 37 текстовых представлений 34 разных хеша: три пары копий одинаковы, остальные одноимённые версии сопоставлены по содержимому.

Сырой корпус содержит регламенты, хендофы, журнал ошибок, пересказ переговоров и отчёты прежних исполнителей. Реальные XML/GSFX, таблицы СВОР/УТВ и оригиналы КП, упоминаемые в текстах, не входят в обнаруженную выборку. Их расчёты и заявленные статусы не проверялись и **не используются как основа или эталон**. Запрет пользователя на такое использование действует до отдельного решения.

## Решения по спорным правилам

| Старое утверждение / эвристика | Решение отдела |
|---|---|
| Всегда использовать старые ФЕР/ФССЦ и индексы из примера | Отклонено: паспорт базы/метода/периода для каждого объекта |
| Брать старый блок целиком при текстовом совпадении | Отклонено: отдельное техническое и нормативное обоснование каждого элемента |
| Удалить все внутренние NotCount | Отклонено по официальной схеме и справке; проверить связи и оплату |
| MaxSysID равно числу позиций | Отклонено по XSD: это максимальный системный идентификатор |
| Удалять любой /100 или везде делить площадь на 100 | Отклонено: перевод зависит от измерителя и режима ввода |
| Quantity всегда только число | Отклонено: разные пути/типы Quantity имеют разную семантику |
| Windows-1251 обязательна для всех XML | Не принято: проверить конкретный формат и байты |
| Средний расход из открытого диапазона закрывает пустое поле | Не принято: требуется применимый расход и техническое основание |
| Очистить все комментарии | Отклонено: сохранить нормативные и проектные основания |
| Ничего не найдено в УТВ — значит нет нормы/цены в базе | Отклонено: фиксировать действительные границы поиска |
| Полное число строк / нулевые ошибки / имя FINAL доказывают готовность | Отклонено: охват, деньги, импорт и утверждение проверяются отдельно |
| Изменённые программой значения автоматически правильны | Отклонено: проверить причину и влияние автокоррекции |
| Подробная видимая детализация требует отдельной оплаты всех строк | Отклонено: разделить информационные строки и оплачиваемые компоненты |
| Всегда нужны ровно три КП, пометка заменяет недостающие документы | Исправлено: категория ресурса, применимые исключения и реальные подтверждения |
| Старая форма КАЦ является текущим эталоном | Не принято: сверить редакцию методики и схему получателя |
| Достаточно PDF рядом или внешнего пути автора | Исправлено: связи и переносимость проверяются на передаваемой копии |
| Свежий хендоф / копия references автоматически каноничны | Не принято: сравнить содержание, точную версию и статус решений |

## Пределы и происхождение

Приватные текстовые снимки, оригинальная структура Google Doc, инвентаризация, хеши и подробные отчёты сохранены локально в `.local/drive-review-2026-09-09/`. Это снимки доступного текста, не архив всех исторических ревизий Drive и не оригинальные расчётные файлы. Номера строк и приватная карта происхождения позволяют вернуться к доказательствам.

В публичный репозиторий включены авторские обезличенные правила и общедоступная документация разработчика. Проектные названия, суммы, переписка, частные ссылки и готовые расчёты не переносятся.

Сценарий уменьшения описан в общем ТЗ, но детальный опыт спринтов преимущественно относится к увеличению. Поэтому наши правила уменьшения и замены — спроектированный процесс с проверяемой арифметикой, а не заявление о выполненных сметах «минус». Значения сокращений СВОР/УТВ установлены по роли документов в контексте; их официальная расшифровка и статус уточняются по новому заданию.

Правомерность конкретных применительных аналогов по действующим редакциям методик требует отдельной проверки: часть первичных нормативных публикаций недоступна. Практический импорт в ГРАНД-Смету и выпуск производственного XML этим исследованием не выполнены.

## Дополнительная проверка описи

CSV содержит шесть строк сводного отчёта о прежних обработках, а не исходные расчёты. Нулевые счётчики и названия FINAL не подтверждают правильность формул, учёта ресурсов или готовность сметы; нужен воспроизводимый протокол по точной версии файла. YAML содержит только название и краткое описание маршрута агента, без расчётных правил. Пустое поле читаемого текста коннектора не означает пустой файл: YAML проверен через получение исходных байтов.

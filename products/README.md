# Утверждённые продукты

Здесь будут архивироваться готовые XML/GGE по схеме `<проект>/<версия>/`. Каждый пакет содержит исходный файл, approval.json, review.md, validation.md и manifest.json.

Сейчас производственных XML нет. Учебный или пустой XML не создаётся для имитации готового продукта.

Правила: [репозиторий и выпуск](../office/repository.md). Локальное архивирование: `tools/archive_xml.py`; шаблон решения: `templates/xml-approval.json`. После публикации проверяются commit SHA и совпадение байтов удалённого файла.

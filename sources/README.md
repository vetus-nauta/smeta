# Реестр источников

Дата подготовки: 09.09.2026. JSON-реестры содержат URL, назначение, дату проверки и состояние доказательств. `checked_on`/`checked_at` — дата обращения, не дата вступления акта в силу. `primary_unavailable` и поисковые реквизиты не означают прочтение документа. Веб-страница разработчика подтверждает функции программы, но не заменяет нормативный акт.

- norms-sources.json — нормативы и образовательная основа.
- grand-sources.json — официальная документация разработчика.
- kac-sources.json — КП, КАЦ, налоговые и форматные основания.
- downloaded-sources.json — фактически скачанные официальные документы и хеши.

Индексация: `python3 tools/office.py index-sources` из корня отдела. Поиск по локальным конспектам: `rg -n 'КАЦ|ФСНБ|НДС' knowledge/`. Полные коммерческие справочники и лицензированные нормативные базы в этот каталог не включены.

При использовании нормы в производственном проекте дополнительно фиксировать: номер и дату акта, регистрацию, официальную публикацию, начало применения, редакцию, пункт и конкретную применимость. Периодические цены/индексы сохранять отдельно в проекте с территорией, кварталом, версией и исходным файлом. Более свежая новость не всегда означает новую применимую редакцию.

`originals/profstandard-97n-appendix.txt` — техническое извлечение текста без табличной вёрстки; для точного взаимного расположения полей использовать оригинальный DOCX.

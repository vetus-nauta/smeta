# Шаблоны отдела

Markdown предназначен для рабочих документов, CSV — для обмена и открытия в табличном редакторе. CSV используют UTF-8 BOM и `;`. Это внутренние рабочие формы; `kac-offers.csv` не заменяет обязательную форму КАЦ по применимой редакции методики или XML для экспертизы.

Пустое поле означает «не заполнено», а не ноль и не отсутствие применимости. В новых реестрах количества, ставки и суммы задаются отдельными числовыми значениями; происхождение и исходное написание сохраняются отдельно. Сохраняйте исходный текст цены и единицы рядом с нормализованными значениями. Для реальных документов указывайте реальные реквизиты; в демонстрациях — заметную маркировку УЧЕБНЫЙ ПРИМЕР.

Табличные редакторы могут интерпретировать текст с `=`, `+`, `-`, `@` как формулу: при импорте непроверенных поставщицких строк выбирайте текстовый тип таких колонок. Формулы и поля паспорта требуют проверки перед выпуском.

Для производственного КАЦ сначала использовать `kac-input-checklist.csv` по [матрице обязательных данных](../office/kac-required-data.md). Строки уровня ресурса/предложения повторить с соответствующими ID; пустые `value_or_register_ref`, `source_file_page_cell`, `decision_id` не заменять вымышленными значениями. `data_status` описывает факт, разрешённая рабочая выдача фиксируется отдельно через решение. В `kac-offers.csv` и `resource-register.csv` добавлены поля КСР, материала, комплектности, адресов и происхождения данных; прежние колонки сохранены.

# Рабочий комплект обработки документов

Установка 09.09.2026 по поручению Алексея. Все операции обработки выполняются локально. Движок распознавания — Tesseract с русским и английским языками; графическое приложение — **gImageReader** в меню системы. Для просмотра и редактирования офисных документов остаётся LibreOffice.

## Состав

- Системные пакеты: tesseract-ocr, tesseract-ocr-rus, tesseract-ocr-eng, ocrmypdf, qpdf, unpaper, gimagereader, python3-venv. Зависимости устанавливаются пакетным менеджером; удаление иных пакетов не выполнялось.
- Python: pdfplumber, pypdf, openpyxl, python-docx, pytesseract, RapidFuzz, opencv-python-headless и их зависимости. Изолированное окружение: `~/.local/share/smetchik/document-tools/venv`; системный Python через pip не изменяется.
- Команда `smeta-python` запускает Python этого окружения. Эталон запуска — [tools/document-python](../tools/document-python); установленная копия — `~/.local/bin/smeta-python`.
- Точные Python-версии — [document-requirements.txt](../tools/document-requirements.txt). Результаты выполненных проверок и версии основных средств — [протокол](../checks/document-tools-acceptance.md).

## Применение

**Ручная работа:** открыть gImageReader, загрузить изображение/PDF, выбрать русский и английский языки, выделить область распознавания. Проверить результат рядом с оригиналом; суммы и знаки просмотреть отдельно. Наличие приложения и запуск справки не означают, что каждый сценарий его интерфейса прошёл проверку.

**Пакетный OCR:** запускать в рабочей папке проекта на копии исходника; имена результатов должны быть новыми. Ниже шаблон команды, пути заменить своими:

```bash
ocrmypdf -l rus+eng --deskew --rotate-pages --jobs 2 --optimize 0 --output-type pdf input-scan.pdf output-ocr.pdf
pdftotext -layout output-ocr.pdf output-ocr.txt
```

Для смешанного PDF допускается `--skip-text`: страницы с существующим текстом будут пропущены. Это не ремонт плохого старого OCR-слоя. `--force-ocr` без отдельного анализа не применять: он растеризует содержимое. Для журналирования слов, координат и уверенности:

```bash
tesseract page.png words -l rus+eng --psm 3 tsv
```

Режим 3 выполняет автоматическую разметку страницы. Режим 6 рассматривает выбранное изображение как единый текстовый блок и применим к подходящей выделенной области; в учебной проверке полной страницы он пропустил таблицу. Для обоих режимов результат проверять по исходнику.

**Таблицы PDF:** pdfplumber извлекает текст, координаты и предполагаемые таблицы. Для таблицы с видимыми границами сначала использовать стандартную стратегию по линиям — она прошла проверку; текстовая стратегия на том же примере обрезала значение. Геометрические стратегии и границы таблиц подбираются по документу; общий успех OCR не подтверждает структуру столбцов. Для PDF без распознанного текста сначала нужен OCR.

**Excel и Word:** openpyxl читает/создаёт XLSX, python-docx — DOCX. openpyxl не вычисляет формулы: `data_only=True` возвращает сохранённый результат, который может отсутствовать или устареть. XLS и DOC требуют предварительного преобразования в LibreOffice в отдельный файл. Для последующего расчёта денежных значений использовать Decimal после явной проверки исходного представления.

**Сопоставление текста:** RapidFuzz даёт оценку сходства строк для поиска кандидатов. Сходство не доказывает эквивалентность материала или расценки. OpenCV установлен для обработки изображения; улучшение точности конкретных сканов с его помощью пока не доказано.

## Обновление и восстановление

```bash
sudo apt-get install --no-install-recommends tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng ocrmypdf qpdf unpaper gimagereader python3-venv
python3 -m venv ~/.local/share/smetchik/document-tools/venv
~/.local/share/smetchik/document-tools/venv/bin/python -m pip install -r tools/document-requirements.txt
~/.local/share/smetchik/document-tools/venv/bin/python -m pip check
```

Команды приведены для воспроизводимости, автоматическое обновление окружения не настроено. Системные версии зависят от репозитория дистрибутива. Путь окружения не включать в Git, пакеты и модели повторно в репозиторий не копировать. После изменения версий проверить контрольный комплект снова и обновить протокол.

Границы применения и денежные проверки — [document-recognition.md](../knowledge/document-recognition.md). Наличие OCR не отменяет ручной проверки спорных цифр, знаков, колонок и итогов. Производственные сметы/КП/КАЦ не распознавались и не утверждались при установке.
